# 路线图

## 已完成：第一期

- 三个讨论角色并行输出方案、风险与调研意见。
- 主控汇总后通过显式开关决定是否进入执行。
- 两个内置只读验证任务并行运行。
- 默认离线模拟模式与完整单元测试。

## 第二期：安全的并行实现（进行中）

- 为目标项目创建隔离 Git worktree。
- 每项实现从稳定 `main` 建立独立 `codex/` 前缀分支；验证通过后再合并。
- 使用任务合同声明允许范围、基线、依赖和验收标准。
- 建立文件范围锁与单写者规则，阻止多个执行者修改同一资源。
- 由验证角色独立复跑测试并检查改动范围。
- 当前实现：任务合同校验、范围锁、Git worktree 创建、改动范围复核和“仅生成合并建议”的门禁；不执行自动合并。

## 第三期：可观察的长期协作

- 持久任务板和运行审计。
- 人工确认界面与暂停/恢复机制。
- 模型调用成本、并发和超时限制。
- 失败恢复、重试策略和真实模型接入。

## 不在范围内

- 自动绕过用户确认或 Codex 权限。
- 多个 Agent 同时写同一个文件、配置或外部系统。
- 在 NAS 或其他设备部署 Agent、后台常驻自动执行，或让子 Agent 绕过主控直接进行 SSH 写入。经用户确认的主控 SSH 远程任务不属于此限制。
